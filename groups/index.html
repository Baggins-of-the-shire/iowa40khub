Local Groups

Public Discords and Facebook groups where Des Moines metro players set up games. Anyone can join from the link.

New to 40k? Start here

Local groups are a great place for a new player to get started. Do your best not to feel nervous about reaching out: people usually love talking about their hobby.

Say hi, mention you're new and which army caught your eye, and ask when people play. That's all it takes.

Run one of these groups and want it changed or taken off? Email bbagginsoftheshire3791@gmail.com or use the feedback form. It's done the same day.
